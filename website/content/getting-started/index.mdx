description: Blume に統合を追加して、ドキュメントサイトを拡張する手順を説明します。
---

`@tai-kun/blume-integrations` は、Blume のドキュメントサイトに小さな機能を追加する Astro 統合のコレクションです。

## 収録されている統合 [#integrations]

| 統合                       | 説明                                                                            | 必要な設定                                    |
| -------------------------- | ------------------------------------------------------------------------------- | --------------------------------------------- |
| `routeByBrowserLanguage()` | デフォルトロケールの URL を、訪問者のブラウザー言語に合うロケールへ転送します。 | Blume の i18n（`defaultLocale` と `locales`） |
| `typeTableDetailsIds()`    | `TypeTable` の各行に固定 ID を付け、プロパティ名をその ID へのリンクにします。  | なし                                          |

## 動作環境 [#requirements]

| パッケージ | バージョン |
| ---------- | ---------- |
| Astro      | 7.0.0 以上 |
| Blume      | 2.0.0 以上 |

## インストール [#install]

```package-install
npm i @tai-kun/blume-integrations
```

## 設定 [#setup]

`blume.config.ts` の `integrations` に追加します。次の例では、`TypeTable` の行に ID を付ける統合を有効にしています。

```ts blume.config.ts
import { typeTableDetailsIds } from "@tai-kun/blume-integrations";
import { defineConfig } from "blume";

export default defineConfig({
  integrations: [typeTableDetailsIds()],
});
```

`routeByBrowserLanguage()` を使う場合は、Blume の i18n の `defaultLocale` に `locales` のいずれかのコードを設定し、デフォルトロケールのコンテンツをコンテンツのルートに置きます。詳しい設定方法は[ブラウザーの言語でルーティング](/guides/route-by-browser-language)を参照してください。
