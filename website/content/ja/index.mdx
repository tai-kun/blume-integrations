`@tai-kun/blume-integrations` は、[Blume](https://useblume.dev) のドキュメントサイトに小さな機能を追加する [Astro](https://astro.build) 統合のコレクションです。静的ビルドのまま使えるため、ホスティング先にサーバーは必要ありません。

## 収録されている統合 [#integrations]

    言語プレフィックスのない URL を、訪問者のブラウザー言語に合うロケールへ転送します。
  </Card>
  <Card title="TypeTable の行に ID を付ける" href="/guides/type-table-details-ids" icon="table">
    `TypeTable` の各行に固定 ID を付け、特定のプロパティへ直接リンクできるようにします。
