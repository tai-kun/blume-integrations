`@tai-kun/blume-integrations` is a collection of [Astro](https://astro.build) integrations that add small features to [Blume](https://useblume.dev) documentation sites. They work with static builds, so no server is required at your hosting provider.

## Included integrations [#integrations]

<CardGroup cols={2}>
  <Card title="Route by browser language" href="/guides/route-by-browser-language" icon="languages">
    Redirect default-locale URLs to the locale that matches the visitor's browser language.
  </Card>
  <Card title="Add IDs to TypeTable rows" href="/guides/type-table-details-ids" icon="table">
    Add stable IDs to each `TypeTable` row so you can link directly to a specific property.
  </Card>
</CardGroup>
